# XLSkills

Hermes Agent 技能（skills）备份仓库。

## 内容

| 目录 | 说明 |
|------|------|
| `XLSkills/` | 开发流程技能集（XLSkills） |
| `dev-pm-flow/` | 开发 PM 流程：拆解→方案→确认→执行→自审→交付（v1.3.4，开源通用版） |
| `requesting-code-review/` | 双轴 pre-commit 审查：Standards + Spec，独立子代理判定（v2.3.3） |
| `systematic-debugging/` | 四阶段根因调试：先闭环后假设（v1.2.2） |

## 使用

```bash
git clone https://github.com/xl188/XLSkills.git
```

> 注意：国内直连 GitHub 可能超时，需走代理（如 `-c http.proxy=***REMOVED***`）。
